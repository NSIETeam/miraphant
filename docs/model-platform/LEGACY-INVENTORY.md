# 历史额度迁移：离线盘点契约

状态：离线只读盘点脚本已通过父任务源码审核、10 项合成检查与独立命令行复核；未读取生产备份，不作为已迁移证明。

## 目的与边界

为实施规格第 6 节提供逐账户原值清单。盘点只读取已制作好的独立 SQLite 备份，不调用生产服务、不启动网关、不执行建表或迁移、不兑换额度。`--migrate-points` 仅迁移账本结构，不承担历史余额转换。

使用独立的 Python 标准库脚本，避免网关启动时自动建表、加载环境或发起网络请求。输入必须是显式指定的备份路径；不得从环境变量猜测线上数据库。脚本以 SQLite `mode=ro` 打开并启用 `query_only`，拒绝带 WAL/SHM/journal 旁文件的输入，并校验 SQLite 文件头为 rollback-journal 格式；WAL 格式必须先由运维生成独立 rollback-journal 备份副本，脚本不 checkpoint、不转换，也不设置 `immutable` 绕过 WAL。读取前后校验主文件 SHA-256、大小和旁文件状态。备份仍需由运维确认完整、一致、已脱离写入进程；仅无旁文件不足以证明生产已排空。

## 输出与数据最小化

输出 JSON 清单，文件权限 0600，默认拒绝覆盖已存在输出；不得覆盖输入。报告只包含白名单字段，不输出密码、访问密钥、兑换码、邮箱、用户名、显示名、日志内容、URL、倍率键名、SQL 错误中的数据或绝对输入路径。失败只返回固定错误类别，不残留本次输出。

- 来源：格式版本、文件字节数、SHA-256、SQLite 用户版本、生成时间；读取前后校验哈希，发现文件改变则失败且不生成报告。
- 用户：ID、角色、状态、原 quota、used_quota、request_count；包括停用和软删除账户并明确状态，不能静默遗漏。
- 访问密钥限额：记录 ID、所属用户 ID、状态、剩余额度、已用额度、无限额标志、到期时间。不得输出密钥或名称；限额不是第二份客户资产，不能与用户余额求和。
- 兑换码：记录 ID、创建者 user_id、状态、额度、创建/兑换时间。user_id 是创建者，不得当成实际兑换用户；状态 1（启用未兑换）与状态 2（禁用未兑换）分别汇总为潜在负债，不加到账户现有余额；状态 3 为已兑换。未知状态作为异常保留。
- 参数：只允许旧额度/计费相关的固定键；缺失数据库选项标记为未持久化，不能假定其为运行时生效值。数字值精确解析；倍率 JSON 仅输出条目数和原值 SHA-256，不输出键名或原文；TopUpLink 仅报告是否配置，不输出 URL。环境变量、缓存与进程参数另需运维取证，报告不代表运行时配置或完整价格映射。
- 日志：若主备份含 logs，仅按类型计数及数值 quota 汇总；不存在则明确未提供，不能显示为零或推断无历史充值。日志可能位于独立数据库或已被清理，汇总不能证明余额购买/赠送来源。
- 已有积分表：若存在 point_accounts/point_holds，报告账户数及整数余额/冻结汇总、hold 状态计数；不输出请求正文、价格快照或业务密钥；与旧 quota 分开，禁止加总。缺表明确为未存在。

所有额度总计使用整数。必需表/列缺失、重复 ID、非整数财务字段、输入损坏或并发变化时失败，不以零值补齐。负数原值保留并列为异常，不擅自取绝对值。不存在的关联用户列为异常，不删除记录。错误输出使用固定类别和白名单结构信息，不泄漏输入数据。

## 后续迁移前置条件

报告不得生成“建议积分”或将历史余额默认视为可退款购买积分。后续需要已确认的换算版本、逐账户来源分类、未用兑换码处理、访问密钥限额映射、日志覆盖说明，以及生产备份/排空证明。历史预扣没有独立可靠证据时标记未知，不能宣称无在途请求。

实际迁移工具须另行实现幂等批次、审批清单哈希绑定、前后总量校验和恢复策略；本盘点节点不开放任何写库选项。

## 验收要求

以合成 SQLite 备份检验精确整数汇总、软删除账户、无限额密钥、未用兑换码分列、缺少可选表、坏表结构、负余额、无主记录及已有积分分离。验证秘密诱饵不出现在报告/错误中、输入哈希和行数不变、拒绝输出覆盖/旁文件、失败不残留报告。只运行本地合成用例，不读取真实生产备份。

运行方式（从仓库根目录，Python 3.10+，Linux/macOS；仅对运维已准备好的独立备份执行）：

```sh
python3 services/gateway/scripts/legacy-inventory.py --input /secure/offline/backup.sqlite3 --output /secure/offline/legacy-inventory.json
python3 services/gateway/scripts/test_legacy_inventory.py
```

脚本只读取主数据库中可用的 `logs`；若生产日志数据库独立存放，该主备份不会覆盖它，报告会明确标记日志未提供。脚本不会合并多个数据库，也不会尝试生成积分换算结果。
